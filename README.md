# 🚗 Projeto 2: Automação de Testes com Python e Selenium — Urban Routes

## 1. Objetivo do Projeto
O objetivo principal deste projeto foi desenvolver scripts robustos para a automação de testes funcionais na interface Web da plataforma Urban Routes. O foco centrou-se em garantir a estabilidade e a integridade dos fluxos principais de utilizador de forma rápida, eficiente e totalmente repetível, reduzindo o esforço de testes manuais.

## 2. Resultado
* **Scripts Estáveis:** Criação e execução de cenários automatizados que validam o comportamento correto dos elementos visuais, formulários e fluxos de agendamento da página.
* **Redução de Tempo:** Otimização do tempo gasto em testes manuais de regressão através da execução automatizada dos fluxos críticos de negócio.
* **Manutenibilidade:** Código modularizado e de fácil leitura, minimizando quebras causadas por futuras alterações no design ou na estrutura do site.

## 3. Ferramentas Utilizadas
* **Linguagem de Programação:** Python.
* **Framework de Testes & Automação:** Selenium WebDriver, Pytest.
* **Padrão de Arquitetura:** POM (Page Object Model).
* **Controlo de Versões:** Git, GitHub.

## 4. O que Aprendi (Habilidades & Competências Adquiridas)
* Implementação prática do padrão Page Object Model (POM) para criar uma estrutura de testes limpa, separando a lógica dos seletores visuais dos scripts de teste.
* Domínio de asserções com Pytest e boas práticas no desenvolvimento de código estável em Python para automação.
* Versionamento correto e organização de fluxos de trabalho utilizando comandos essenciais do Git.

## 5. Existem Melhorias a Serem Feitas?
Sim. Como próximos passos para este projeto, planeio:
1. **Integração em CI/CD:** Configurar um pipeline simples de Integração Contínua utilizando GitHub Actions para correr os testes de forma automática a cada novo envio de código.
2. **Testes em Paralelo:** Implementar a execução de testes em paralelo para acelerar ainda mais o feedback sobre a estabilidade do sistema.
